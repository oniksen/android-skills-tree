# Roadmap на больших экранах: граф всех тем грейда

**Дата:** 2026-11-23  
**Статус:** на утверждении  
**Область:** `src/data`, `src/core/domain`, `src/features/roadmap`, `AGENTS.md`.

## 1. Зачем

Страница `/roadmap` должна помогать понять, что уже пройдено, что сейчас в изучении,
что осталось закрыть и в каком порядке двигаться. Сейчас `RoadmapClient` берёт все навыки
текущего грейда, сортирует их по XP или проценту закрытия и выводит плоским списком
`GapList`. После перехода на широкую сетку карточки стали крупнее, но структура и порядок
так и не появились.

Нужна диаграмма для больших экранов; на мобильных остаётся текущий список.

## 2. Цели, не-цели, анти-цели

**Цели**
- Показать на больших экранах **все** навыки текущего грейда.
- Сгруппировать их по категориям (колонки), чтобы 80+ junior-навыков читались.
- Показать связи между навыками из отдельного файла.
- Отметить три состояния: `пройдено`, `в изучении`, `осталось закрыть`.
- Отметить дополнительные (не обязательные для перехода) навыки особой рамкой.
- Не менять мобильный сценарий: ниже `xl` остаётся текущий `GapList`.

**Не-цели**
- Не менять правила XP, уровней, кристаллов и достижений.
- Не менять `src/data/skills/*` и `src/data/categories.ts`.
- Не добавлять графовые библиотеки (`@xyflow/react`, `dagre`, `mermaid`).
- Не строить межгрейдовый граф: диаграмма показывает только текущий грейд.
- Не переносить изучение материалов в диаграмму.

**Анти-цели**
- Диаграмма, которая прячет часть навыков грейда.
- Одна колонка на 80 узлов без структуры.
- Ручная раскладка координат в data-файле (хрупко при добавлении навыков).
- Тяжёлый JS-бандл на мобильных.
- Циклы или «висячие» ID в связях, ломающие страницу.

## 3. Решение

Выбран **вариант B**: свой SVG-рендер без новых зависимостей.

- Связи хранятся в `src/data/roadmap-links.ts` — массив рёбер `from`/`to` по
  существующим human-readable ID навыков и тип связи.
- Чистая доменная функция собирает **все** навыки текущего грейда, раскладывает их по
  колонкам категорий и считает статусы.
- На `xl+` рендерится SVG-диаграмма с горизонтальной прокруткой; ниже `xl` —
  текущий `GapList`.
- Никаких новых пакетов в `package.json`.

## 4. Модель данных связей

**Файл:** `src/data/roadmap-links.ts`

```ts
export type RoadmapLinkKind = "requires" | "recommends";

export interface RoadmapLink {
  /** Навык, который изучается раньше. */
  from: string;
  /** Навык, который открывается после `from`. */
  to: string;
  kind: RoadmapLinkKind;
}

export const ROADMAP_LINKS: RoadmapLink[] = [
  { from: "junior-osnovy-perem", to: "junior-osnovy-tipy", kind: "requires" },
  { from: "junior-osnovy-uslov", to: "junior-osnovy-cikly", kind: "requires" },
  { from: "junior-kotlin-sintaks", to: "junior-kotlin-null", kind: "requires" },
];
```

Правила:
- `requires` — жёсткая зависимость: рисуется сплошной стрелкой.
- `recommends` — мягкий порядок: рисуется пунктирной стрелкой.
- `from` и `to` обязаны существовать в `skills`; проверяется тестом.
- `from` и `to` обязаны относиться к одному грейду; межгрейдовые рёбра запрещены и
  проверяются тестом. Диаграмма показывает только текущий грейд.
- Граф должен быть ацикличным; проверяется тестом. В рантайме цикл не роняет страницу.
- Один и тот же `from → to` не дублируется.
- Навык без связей всё равно попадает на диаграмму — в колонку своей категории.

## 5. Доменный слой

**Файл:** `src/core/domain/roadmap-graph.ts` (рядом `roadmap-graph.test.ts`).

```ts
export type RoadmapNodeStatus = "done" | "in-progress" | "remaining";

export interface RoadmapGraphNode {
  skillId: string;
  name: string;
  categoryId: string;
  categoryName: string;
  status: RoadmapNodeStatus;
  completionPercent: number;
  requiredForLevelUp: boolean;
  /** Индекс колонки категории. */
  column: number;
  /** Индекс внутри колонки (по sortOrder). */
  row: number;
}

export interface RoadmapGraphEdge {
  from: string;
  to: string;
  kind: RoadmapLinkKind;
}

export interface RoadmapGraphColumn {
  categoryId: string;
  categoryName: string;
  skillIds: string[];
}

export interface RoadmapGraph {
  levelId: string;
  levelName: string;
  nodes: RoadmapGraphNode[];
  edges: RoadmapGraphEdge[];
  columns: RoadmapGraphColumn[];
}

export function buildRoadmapGraph(params: {
  levelId: string;
  assessmentMap: Record<string, { subtopics?: Record<string, boolean> }>;
  links: RoadmapLink[];
}): RoadmapGraph;
```

### 5.1 Состав узлов

- `levelSkills = getSkillsByLevelId(levelId)` — **все** навыки грейда.
- `levelCategories = getCategoriesByLevelId(levelId)`, отсортированные по `sortOrder`.
- Для каждой категории навыки сортируются по `skill.sortOrder`, затем по `id`.
- `column` — индекс категории; `row` — индекс навыка внутри категории.
- `columns` — `{ categoryId, categoryName, skillIds }` в порядке категорий.
- `edges` — только связи, у которых оба конца входят в `levelSkills`. Межгрейдовые и
  неизвестные рёбра отбрасываются в рантайме; тест данных обязан их отловить.

### 5.2 Статусы

- `completionPercent = calcSkillCompletionPercent(skillId, assessmentMap[skillId]?.subtopics)`.
- `done` — 100%.
- `in-progress` — больше 0 и меньше 100.
- `remaining` — 0%.
- `requiredForLevelUp` переносится из навыка отдельным булевым флагом.
- Наличие/отсутствие связей на статус не влияет: связи показывают порядок, а не
  блокировку. Пользователь может изучать темы в любом порядке.

### 5.3 Циклы и неизвестные ID

- Тест на реальных данных обязан падать при цикле, неизвестном ID или межгрейдовом ребре.
- В рантайме `buildRoadmapGraph` не бросает исключение: неизвестные/межгрейдовые рёбра
  игнорируются, а цикл не мешает раскладке по категориям (она не топологическая).
- Колонки и строки всегда строятся по `sortOrder`, поэтому граф детерминирован.

## 6. Рендер

**Файл:** `src/features/roadmap/components/RoadmapDiagram.tsx` (client, `useRouter`).

- SVG без сторонних библиотек.
- Колонки — категории с заголовком; узлы — навыки сверху вниз по `row`.
- Константы раскладки: `NODE_W = 200`, `NODE_H = 56`, `COL_W = 240`, `ROW_H = 76`,
  `PADDING = 24`.
- Узел: `rect` + название навыка (обрезается с `…`, полное имя — в `<title>`) +
  процент закрытия. Дополнительно можно показать мини-прогресс внутри узла.
- Цвета статусов:
  - `done` — emerald;
  - `in-progress` — blue (акцент);
  - `remaining` — slate.
- **Особая рамка:** если `requiredForLevelUp === false` (дополнительный навык), рамка
  пунктирная. Обязательные навыки — обычная сплошная рамка. Легенда объясняет разницу.
- Стрелки: кубическая кривая от правого/левого центра `from` к ближайшему центру `to`;
  `requires` — сплошная, `recommends` — пунктирная; `marker-end` со стрелкой.
- Контейнер `overflow-x-auto`; высота — по контенту. Никакого pan/zoom.
- Клик и `Enter`/`Space` ведут в навык через `treeSkillHref`/`skillDetailHref`
  (как в `GapList`); `role="link"`, `tabIndex={0}`, `aria-label`.
- Легенда над диаграммой: `Пройдено` / `В изучении` / `Осталось закрыть` /
  `Дополнительный` (пунктир).
- Пустой граф (`nodes.length === 0`) — короткое сообщение, без пустого SVG.

## 7. Интеграция со страницей

**Файл:** `src/features/roadmap/components/RoadmapClient.tsx`.

- Hero и `PageSummaryCard` остаются для всех разрешений.
- Тулбар сортировки и «Скрыть пройденные» относится только к списку, поэтому
  скрывается на `xl+` (`xl:hidden`).
- `graph = buildRoadmapGraph({ levelId: currentLevel.id, assessmentMap, links: ROADMAP_LINKS })`.
- Выше `xl`: `<div className="hidden xl:block"><RoadmapDiagram ... /></div>`.
- Ниже `xl`: `<div className="xl:hidden"><GapList ... /></div>`.
- Колонки категорий делают диаграмму читаемой даже без связей, поэтому отдельный
  fallback на список для «пустых» грейдов не нужен. Если `nodes.length === 0`, диаграмма
  показывает сообщение, а список остаётся доступен на всех разрешениях.
- `RoadmapSkeleton` не меняется.
- `GapList` и `sortRoadmapItems` не меняются.

## 9. Крайние случаи и риски

- **Junior — самый плотный грейд (82 навыка, 10 категорий).** Колонки категорий дают
  ~8 узлов на колонку и горизонтальную прокрутку; это читаемее одной колонки.
- **Мало связей.** Навыки без рёбер остаются в своих колонках; граф всё равно показывает
  состав грейда и статусы. По мере наполнения `ROADMAP_LINKS` появляются стрелки.
- **Senior.** 56 навыков в 12 категориях; принцип тот же.
- **Цикл в данных.** Тест падает; рантайм не роняет страницу.
- **Мобильный бандл.** Диаграмма без зависимостей; `hidden xl:block` достаточно.
  Если размер станет проблемой — вынести в `next/dynamic` с медиа-гейтом.
- **Длинные названия.** Обрезка с `…` + `<title>`.
- **Тёмная/светлая тема.** Использовать remapped Tailwind-токены проекта.

## 10. Что остаётся на усмотрение исполнителя

- Точная стилистика узлов/стрелок и легенды в рамках существующего терминального вида.
- Показывать ли внутри узла мини-прогресс-бар или только процент.
- Начальный набор рёбер: достаточно покрыть junior-путь; дальше файл пополняется.
- Нужна ли горизонтальная подсказка прокрутки.

## 11. Рассмотренные подходы

- **A. React Flow + layout-библиотека.** Ближе к roadmap.sh, pan/zoom, но две новые
  зависимости, автолэйаут на 80+ узлах и выгрузка модуля на мобильных. Отклонён.
- **B. Своя SVG-диаграмма с колонками категорий (выбран).** Ноль зависимостей, все
  навыки, контроль над стилем, детерминированная раскладка, тестируемая доменная логика.
- **C. Только «следующий шаг» без диаграммы.** Дешевле, но не даёт общей картины.
